# Görseller

Sayfalar bu klasördeki dosyaları otomatik olarak kullanır. Dosya yoksa yerine çizim veya kısaltma rozeti gösterilir.

| Dosya | Nerede görünür |
|---|---|
| `dota2-logo.png` | Banner arka planı ve sekme simgesi (favicon) |
| `items/sabatons_of_mordiggian.png` | Sabatons of Mordiggian kartı ve ikonları |
| `items/greater_horn_of_battle.png` | Greater Horn of Battle (yeni item kartı ve Tormentor bölümü) |
| `creeps/radigull.png` | Yeni neutral creep kartı: Radigull |
| `creeps/odobenus.png` | Yeni neutral creep kartı: Odobenus |
| `creeps/eimermole.png` | Yeni neutral creep kartı: Eimermole |
| `creeps/ancient_ogre_seal.png` | Yeni neutral creep kartı: Ancient Ogre Seal |
| `map-7.42.png` | (planlanan) Gerçek harita görseli |

Kare ve şeffaf arka planlı PNG önerilir. Creep görselleri daire içinde kırpılarak gösterilir.
